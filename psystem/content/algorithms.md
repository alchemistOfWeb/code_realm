### Нотация O-большое

- **O-большое** — верхняя оценка роста времени или памяти алгоритма при больших n, без констант и младших слагаемых.
- **Константная сложность** — O(1): время не зависит от размера входа, например доступ к элементу массива по индексу.
- **Линейная сложность** — O(n): один проход по данным.
- **Логарифмическая сложность** — O(log n): на каждом шаге задача уменьшается в разы, как в бинарном поиске.

Порядок роста: O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!).

```python
def has_duplicate(nums):          # O(n²): два вложенных цикла
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] == nums[j]:
                return True
    return False

def has_duplicate_fast(nums):     # O(n): множество
    return len(set(nums)) != len(nums)
```

Константы отбрасываются: `O(2n + 5)` = `O(n)`. Складываются последовательные части, перемножаются вложенные.

### Время и память

Кроме времени важна **пространственная сложность** — сколько дополнительной памяти нужно алгоритму.

- **Пространственная сложность** — объём дополнительной памяти в зависимости от n (без учёта самого входа).
- **Компромисс время-память** — часто можно ускорить алгоритм, потратив память (кэш, хеш-таблица, предподсчёт).

```python
def fib(n, memo={}):      # время O(n), память O(n) на мемо и стек вызовов
    if n < 2:
        return n
    if n not in memo:
        memo[n] = fib(n - 1) + fib(n - 2)
    return memo[n]
```

Рекурсия тратит память на **стек вызовов**: глубина рекурсии n → O(n) памяти.

### Динамический массив

Python `list` — **динамический массив**: элементы лежат подряд, доступ по индексу за O(1), вставка в начало — O(n).

- **Динамический массив** — массив, который при заполнении выделяет больший блок памяти и копирует туда элементы.
- **Срез** — `a[i:j]` создаёт новую копию за O(j − i).

```python
a = [3, 1, 4]
a.append(1)        # O(1) амортизированно
a.insert(0, 9)     # O(n): сдвиг всех элементов
a[1:3]             # копия [3, 1]
```

### Два указателя

- **Два указателя** — приём, когда два индекса движутся по массиву навстречу или в одну сторону, заменяя вложенный цикл одним проходом.

```python
def two_sum_sorted(nums, target):   # nums отсортирован, O(n)
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target:
            return l, r
        if s < target:
            l += 1
        else:
            r -= 1
    return None

def is_palindrome(s):
    s = [c.lower() for c in s if c.isalnum()]
    return s == s[::-1]
```

### Скользящее окно

- **Скользящее окно** — подотрезок массива, который расширяют справа и сужают слева, поддерживая нужное свойство за один проход.

```python
def longest_unique_substring(s):     # O(n)
    seen = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1
        seen[ch] = right
        best = max(best, right - left + 1)
    return best
```

### Префиксные суммы

- **Префиксная сумма** — массив, где p[i] — сумма первых i элементов; сумма отрезка [l, r) считается как p[r] − p[l] за O(1).

```python
from itertools import accumulate
nums = [2, 4, 1, 3]
p = [0, *accumulate(nums)]     # [0, 2, 6, 7, 10]
range_sum = p[3] - p[1]        # 4 + 1 = 5
```

## Хеш-таблицы <!-- difficulty: 1 -->

### Как устроена хеш-таблица

- **Хеш-функция** — функция, превращающая ключ в число, по которому выбирается ячейка таблицы.
- **Коллизия** — ситуация, когда разные ключи попадают в одну ячейку.
- **Коэффициент заполнения** — доля занятых ячеек; при его росте таблица увеличивается и элементы перераспределяются.

Коллизии решают **цепочками** (список в ячейке) или **открытой адресацией** (поиск следующей свободной ячейки — так в CPython).

Ключ должен быть **хешируемым**: неизменяемым и с постоянным `hash`. Поэтому `list` не может быть ключом, а `tuple` из чисел — может.

### Подсчёт частот и two sum

```python
from collections import Counter

def is_anagram(a, b):
    return Counter(a) == Counter(b)

def two_sum(nums, target):           # O(n) вместо O(n²)
    index = {}
    for i, x in enumerate(nums):
        if target - x in index:
            return index[target - x], i
        index[x] = i
```

- **Counter** — словарь-счётчик из `collections`: считает, сколько раз встречается каждый элемент.

### Устройство связного списка

- **Связный список** — цепочка узлов, где каждый хранит значение и ссылку на следующий узел.
- **Двусвязный список** — узлы хранят ссылки и на следующий, и на предыдущий элемент.

Доступ по индексу — O(n), но вставка/удаление при известном узле — O(1). `collections.deque` реализован на двусвязных блоках.

```python
class Node:
    def __init__(self, val, next=None):
        self.val, self.next = val, next

head = Node(1, Node(2, Node(3)))
```

### Разворот списка

```python
def reverse(head):
    prev = None
    while head:
        head.next, prev, head = prev, head, head.next
    return prev
```

Классика собеса: развернуть итеративно (O(1) памяти) и рекурсивно (O(n) стек вызовов).

### Быстрый и медленный указатель

- **Алгоритм Флойда** — поиск цикла в списке: медленный указатель шагает на 1, быстрый на 2; если есть цикл, они встретятся.

```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            return True
    return False
```

Тот же приём находит середину списка: когда быстрый дошёл до конца, медленный — в середине.

### Стек

- **Стек** — структура LIFO: последним пришёл — первым вышел; операции push и pop за O(1).

В Python стек — обычный `list` (`append` / `pop`).

```python
def valid_brackets(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
            return False
    return not stack
```

### Монотонный стек <!-- optional -->

- **Монотонный стек** — стек, элементы которого всегда упорядочены; позволяет найти ближайший больший/меньший элемент за O(n).

```python
def next_greater(nums):
    res = [-1] * len(nums)
    stack = []                        # индексы, значения убывают
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        stack.append(i)
    return res
```

### Рекурсия и стек вызовов

```python
def factorial(n):

        return 1
    return n * factorial(n - 1)
```

### Перебор с возвратом

- **Backtracking** — построение решения по шагам с откатом последнего выбора, если он ведёт в тупик.

```python
def permutations(nums):
    res, path, used = [], [], [False] * len(nums)
    def go():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i, x in enumerate(nums):
            if not used[i]:
                used[i] = True; path.append(x)
                go()
                path.pop(); used[i] = False    # откат
    go()
    return res
```

Задачи: перестановки, подмножества, N ферзей, судоку, комбинации с суммой.

### Квадратичные сортировки

- **Сортировка пузырьком** — многократно меняет местами соседние элементы, стоящие не по порядку; O(n²).
- **Сортировка вставками** — вставляет каждый элемент на своё место в уже отсортированной части; O(n²), но быстра на почти отсортированных данных.

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        x, j = a[i], i - 1
        while j >= 0 and a[j] > x:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = x
```

### Сортировка слиянием

- **Сортировка слиянием** — делит массив пополам, сортирует половины рекурсивно и сливает; всегда O(n log n), память O(n).

```python
def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    res, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i]); i += 1
        else:
            res.append(right[j]); j += 1
    return res + left[i:] + right[j:]
```

### Классический бинарный поиск

- **Бинарный поиск** — поиск в отсортированном массиве делением отрезка пополам; O(log n).

```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

Главное условие — массив **отсортирован**.

### Бинарный поиск по ответу <!-- optional -->

- **Бинарный поиск по ответу** — подбор минимального подходящего значения, если проверка «подходит ли x» монотонна.

```python
def min_speed(piles, hours):          # «Коко ест бананы»
    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        if sum((p + mid - 1) // mid for p in piles) <= hours:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

### Двоичные деревья и обходы

- **Двоичное дерево** — дерево, у каждого узла которого не больше двух детей.
- **Обход в глубину** — посещение узлов с уходом вглубь ветки: прямой (pre-order), центрированный (in-order) и обратный (post-order).
- **Обход в ширину** — посещение узлов по уровням с помощью очереди.

```python
def inorder(node):
    if node:
        yield from inorder(node.left)
        yield node.val
        yield from inorder(node.right)

def max_depth(node):
    return 0 if node is None else 1 + max(max_depth(node.left), max_depth(node.right))
```

### Префиксное дерево

- **Trie** — дерево, где каждый путь от корня — префикс строки; поиск слова или префикса за O(длины слова).

```python
class Trie:
    def __init__(self):
        self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True
    def starts_with(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node:
                return False
            node = node[ch]
        return True
```

### Обход в ширину и в глубину

```python
from collections import deque

def bfs(graph, start):          # кратчайший путь в рёбрах в невзвешенном графе
    dist = {start: 0}
    q = deque([start])
    while q:
        v = q.popleft()
        for u in graph[v]:
            if u not in dist:
                dist[u] = dist[v] + 1
                q.append(u)
    return dist

def dfs(graph, v, seen):
    seen.add(v)
    for u in graph[v]:
        if u not in seen:
            dfs(graph, u, seen)
```

Обе работают за O(V + E). BFS даёт кратчайшие пути в невзвешенном графе, DFS — компоненты связности, поиск циклов.

### Топологическая сортировка

- **Топологическая сортировка** — упорядочивание вершин ориентированного графа без циклов так, чтобы каждое ребро шло слева направо.

```python
from collections import deque

def topo_sort(n, edges):        # алгоритм Кана
    indeg = [0] * n
    graph = [[] for _ in range(n)]
    for a, b in edges:
        graph[a].append(b); indeg[b] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        v = q.popleft(); order.append(v)
        for u in graph[v]:
            indeg[u] -= 1
            if indeg[u] == 0:
                q.append(u)
    return order if len(order) == n else None   # None — есть цикл
```

Применение: порядок сборки зависимостей, расписание курсов.

### Алгоритм Дейкстры

- **Алгоритм Дейкстры** — поиск кратчайших путей от одной вершины во взвешенном графе с неотрицательными весами; O((V + E) log V) с кучей.

```python
import heapq

def dijkstra(graph, start):          # graph[v] = [(u, w), ...]
    dist = {start: 0}
    heap = [(0, start)]
    while heap:
        d, v = heapq.heappop(heap)
        if d > dist.get(v, float("inf")):
            continue
        for u, w in graph[v]:
            nd = d + w
            if nd < dist.get(u, float("inf")):
                dist[u] = nd
                heapq.heappush(heap, (nd, u))
    return dist
```

При отрицательных весах нужен **алгоритм Беллмана — Форда** (O(V·E)).

### Система непересекающихся множеств <!-- optional -->

- **Union-Find** — структура, которая хранит разбиение на группы и умеет объединять группы и проверять, в одной ли группе элементы; почти O(1) на операцию.

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]   # сжатие путей
        x = parent[x]
    return x
def union(a, b):
    parent[find(a)] = find(b)
```

Применение: компоненты связности, алгоритм Краскала для минимального остовного дерева.

### Одномерная ДП

```python
def climb_stairs(n):          # шаги по 1 или 2 ступени

def rob(houses):              # «грабитель»: нельзя брать соседние дома
```

### Двумерная ДП

```python
def lcs(a, b):                # наибольшая общая подпоследовательность, O(n·m)
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[-1][-1]
```

- **Задача о рюкзаке** — выбор предметов с весами и ценностями в рюкзак ограниченной вместимости; dp по предметам и весу за O(n·W).
- **Расстояние Левенштейна** — минимальное число вставок, удалений и замен символов, превращающих одну строку в другую.

### Жадные алгоритмы <!-- optional -->

- **Жадный алгоритм** — на каждом шаге делает локально лучший выбор; работает, только если локальный оптимум ведёт к глобальному.

```python
def max_meetings(intervals):          # выбор непересекающихся встреч
    count, end = 0, float("-inf")
    for s, e in sorted(intervals, key=lambda x: x[1]):
        if s >= end:
            count += 1
            end = e
    return count
```

Контрпример: размен монетами 1, 3, 4 суммы 6 — жадно 4+1+1 (3 монеты), а оптимально 3+3 (2 монеты). Тогда нужна ДП.
