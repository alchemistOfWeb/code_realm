# CodeRealm

Геймифицированная RPG-система изучения знаний на Godot 4.6 (GDScript, Compatibility).
Изучай темы пяти специализаций → получай XP, уровни, энергию и карты → отправляйся в вылазки по карте мира,
сражайся карточными боями, собирай снаряжение.

## Запуск

Открой папку `psystem` в Godot 4.6 и нажми **F5**. Главная сцена — `scenes/main/Main.tscn`.
Игра начинается с главного меню: выбери героя (профиль) или создай нового — раса, пол и внешность.
Язык (русский / English) переключается в главном меню и в настройках.

## Управление

- Клик по сфере — дерево специализации, клик по узлу — урок. На странице урока `←` / `→` — соседние темы.
- `Esc` / боковая кнопка мыши «назад» — предыдущий экран; на главном экране `Esc` — меню (главное меню, титры, выход).
- Иконки в HUD: карта мира, лавка, персонаж, настройки, меню.
- **Вылазка:** `WASD` — ходьба (относительно камеры), `Shift` — бег (тратит выносливость), `F` — прыжок,
  `E` — действие, `M` — крупная карта, `Space` — пауза, `Esc` — меню вылазки. Камера: правая кнопка мыши — вращение,
  колесо — приближение, `Q`/`R` — поворот. Клавиши переназначаются в настройках (раздел «Управление в вылазках»).

## Мир

- **Карта мира** — 100 локаций с рекомендуемым уровнем и процентом исследования. Сейчас доступны «Шепчущая роща»
  и «Руины Феррограда», остальные — в разработке.
- **Карта локации** — подлокации, соединённые тропами. Начать вылазку (−10 энергии) можно в открытую подлокацию:
  стартовую или ту, проход в которую уже найден из соседней. Найденные проходы позволяют потом сразу идти в дальние точки.
- Падение в пропасть или реку — гибель: вся энергия теряется, герой возвращается в лагерь.
- **Лавка** продаёт оружие, щиты, броню и украшения (карты — только из сундуков, тестов и боёв).
- **Персонаж → Снаряжение** — кукла героя и инвентарь (без ограничений веса). Оружие задаёт атаки в бою, броня даёт щит.

## Контент

Учебные материалы — markdown-файлы в `content/`, список специализаций — `data/specializations.json`.
Новый `.md` в `content/` подхватывается автоматически как новая специализация.
Разметка: `##` — раздел (узел дерева), `###` — подтема; маркеры в заголовках:
`<!-- difficulty: 2 -->`, `<!-- optional -->` (фиолетовый узел), `<!-- skip -->`.
Вопрос для тестов — отдельной строкой в тексте темы (в превью не виден):
`<!-- quiz: Вопрос? | +Верный ответ | Неверный | Неверный || Пояснение -->`.

## Тесты и награды

- «Пройти тест» в уроке — 3–5 вопросов по теме; зачёт (60%) отмечает тему изученной и даёт бонус XP.
- «Пройти общий тест» в дереве — 10 вопросов; зачёт (70%) → свиток наград: XP, энергия и 1–3 карты.
- За каждый новый уровень — сундук с картой (кнопка с сундуком в HUD или в коллекции карт).

## Заметки для Claude

В каждом уроке есть поле «Заметки для Claude», общие заметки — кнопка «Заметки» в HUD.
Всё экспортируется в `NOTES_FOR_CLAUDE.md` (автоматически при сохранении заметки и при выходе).

## Инструменты разработчика

```bash
# Перегенерировать тему UI после правок scripts/utils/ThemeFactory.gd
Godot --headless --path . --script res://tools/build_theme.gd
# Отчёт по распарсенному контенту
Godot --headless --path . --script res://tools/content_report.gd -- --verbose
# Smoke-тест логики и навигации (код выхода 0 = всё ок)
Godot --headless --path . res://tools/SmokeTest.tscn
# Генерация вопросов тестов по деревьям (с примерами)
Godot --headless --path . res://tools/QuizReport.tscn -- --sample
# Скриншот экрана (dev-аргументы после "--"), --lang=en — английский без сохранения в настройки
Godot --path . -- --demo --screen=sortie:whisper_grove:brook --look=platforms --shot=C:/tmp/shot.png
# Просмотр модели героя или монстра
Godot --path . res://tools/ModelViewer.tscn -- --hero=female --race=tiefling --weapon=Sword --anim=Idle --shot=C:/tmp/hero.png
# Локализация: собрать новые строки в locale/en.json и выгрузить непереведённые
python tools/i18n/extract.py --missing missing.json
# Перегенерировать карту мира / добавить новые карты
python tools/gen_world_map.py
python tools/gen_cards.py
```

Профили и сохранения: `%APPDATA%/Godot/app_userdata/CodeRealm/profiles/` (список — `profiles.json`).
Настройки: `%APPDATA%/Godot/app_userdata/CodeRealm/settings.cfg`.
