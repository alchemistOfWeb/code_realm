# code_realm

**CodeRealm** — геймифицированная RPG-система изучения знаний на Godot 4.6 (GDScript).
Изучай темы пяти специализаций (Python Developer, AI/LLM Engineer, Python Backend, Game Designer,
Level Designer) → получай опыт, уровни, энергию и карты → создай героя (6 рас, взрослые модели в стиле WoW),
выбирай локацию на карте мира из 100 земель и отправляйся в вылазки: поляны, леса, пещеры и гробницы,
прыжки по движущимся платформам, диалоги, где знания открывают реплики, загадки, сейфы с Python-кодом
и карточные бои. Лавка снаряжения, инвентарь, профили, русский и английский языки.

- Проект Godot: [`psystem/`](psystem/) (открыть в Godot 4.6, F5).
- Описание, управление и команды разработчика: [`psystem/README.md`](psystem/README.md).
- Обзор архитектуры: [`GODOT_RPG_PROMPT.md`](GODOT_RPG_PROMPT.md).
