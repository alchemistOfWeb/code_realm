# code_realm

**CodeRealm** — геймифицированная RPG-система изучения знаний на Godot 4.6 (GDScript).
Изучай темы пяти специализаций (Python Developer, AI/LLM Engineer, Python Backend, Game Designer,
Level Designer) → получай опыт, уровни, энергию и карты → отправляйся в экспедиции: диалоги,
где знания открывают реплики, загадки, сейфы с Python-кодом и карточные бои.

- Проект Godot: [`psystem/`](psystem/) (открыть в Godot 4.6, F5).
- Описание и команды разработчика: [`psystem/README.md`](psystem/README.md).
- Обзор архитектуры: [`GODOT_RPG_PROMPT.md`](GODOT_RPG_PROMPT.md).
